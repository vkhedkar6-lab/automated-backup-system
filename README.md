# Automated Backup System Using Python and GitHub Actions

## About the Project
The Automated Backup System automates the process of creating ZIP backups using Python and GitHub Actions.

## Technologies Used
- Python
- GitHub
- GitHub Actions
- YAML
- ZIP Compression

## Features
- Automated backup creation
- Timestamp-based backup filenames
- ZIP file compression
- GitHub Actions workflow automation
- Version control using GitHub
- Error handling for backup failures

## How It Works
1. Python scans the project directory.
2. Project files are collected.
3. Files are compressed into a ZIP archive.
4. A timestamp is added to the backup filename.
5. GitHub Actions executes the Python script.
6. The generated backup is uploaded as a workflow artifact.
